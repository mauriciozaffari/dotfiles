# Concise

**Key:** `concise`

Short and to the point. Focus on essential requirements only.

## When to use

- Small, well-understood changes where ceremony adds no value.
- The reader already has context; you just need to capture the ask.

## Guidance

- Lead with a single sentence stating what to do.
- Follow with a tight bullet list of essential requirements only.
- No acceptance criteria, no background, no edge-case exploration unless critical.
- Cut anything that isn't needed to act on the ticket.

## Example

```
Add login button to header.

- Button should link to /login
- Use primary color styling
```
